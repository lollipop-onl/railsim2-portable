# Capture / AVI / DirectShow no-op (`#76`, parent `#17`)

F12 stills, AVI record, hidef `CopyRects` tiles, and DirectShow playback are **out of M3**. This slice cuts those paths so bring-up does not link `vfw32` or a real FilterGraph. `AVIFileInit` / `AVIFileExit` / `AVIFileOpen` / `AVIFileCreateStream` / `AVIStreamSetFormat` / `AVIStreamWrite` / `AVIStreamRelease` / `AVIFileRelease` live in `port/stub/vfw.h` as link-free no-ops (open/write return `E_NOTIMPL`). `IGraphBuilder` / `IMediaControl` / `IMediaEventEx` / `IVideoWindow` live in `port/stub/dshow.h` as opaque COM stubs; `lib/movie.cpp` `InitDirectShow` returns `TRUE` with a NULL graph (same soft-fail as `InitDirectSound`) and `PlayMovie` / `StopMovie` do not assert. `Capture.cpp` is on `port/native_sources.txt`. `InitCapture` still creates `Picture/` and `Video/` under `g_BaseDir`; `VideoCapture` / `StartVideoCapture` / `StopVideoCapture` / `HidefCapture` return immediately (original AVI / `BitBlt` / hidef bodies stay under `#if 0`). `lib/movie.cpp` is compiled into `railsim2_native` so the DirectShow stub is parsed. **`#16` owns the GDI `CPixelbit` DIB / `HFONT` / `DrawInText` replacement.** The two `BitBlt` window-DC readbacks in `Capture.cpp` stay enumerated in [gdi-seams.md](gdi-seams.md); they are not implemented here (no PNG, no AVI encode, no GDI swap).
