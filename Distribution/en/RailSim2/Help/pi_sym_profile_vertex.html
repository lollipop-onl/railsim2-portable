概要

断面の頂点を定義します。

生成規則

profile-vertex ::=
Vertex{
    ( IgnoreCant = yes-no; )opt
    Coord = vector-2d;
    ( Normal = vector-2d; )opt
    ( Diffuse = color; )opt
    ( TexU = float; )cond
}

解説

IgnoreCant

カントの影響を無視するかどうか指定します。バラストの底辺など、カントの影響を無視すべき頂点で yes を指定します。デフォルト値は no です。

Normal

頂点における法線方向を指定します。省略した場合、隣接する頂点座標から自動的に計算されます。

Diffuse

頂点におけるポリゴンの色を指定します。デフォルト値は #ffffffff です。

TexU

profile でUseTexture = yes; を指定した場合のみ記述します。頂点のテクスチャマッピング U 座標値を指定します。
