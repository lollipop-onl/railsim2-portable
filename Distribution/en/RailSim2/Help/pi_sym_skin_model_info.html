概要

スキンの各種モデルに関する定義です。

生成規則

skin-model-info ::=
Model{
    ArrowModelFileName = filename;
    ArrowModelScale = float;
    LinkModelFileName = filename;
    LinkModelScale = float;
    SegmentModelFileName = filename;
    SegmentModelScale = float;
    CompassModelFileName = filename, filename;
    CompassModelScale = float, float;
    WindDirModelFileName = filename;
    WindDirModelScale = float;
}

解説

ArrowModelFileName

線路設置時の 3D 矢印モデルを指定します。

ArrowModelScale

その読込スケール。

LinkModelFileName

線路接続字のインディケータの 3D 矢印モデルを指定します。

LinkModelScale

その読込スケール。

SegmentModelFileName

線路の分割範囲を示すインディケータのモデルを指定します。

SegmentModelScale

その読込スケール。

CompassModelFileName

コンパスに使用するモデルを目盛りと磁針の 2 個指定します。

CompassModelScale

その読込スケール。

WindDirModelFileName

風速計に使用する 3D 矢印のモデルを指定します。

WindDirModelScale

その読込スケール。
