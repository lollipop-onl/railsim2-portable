History

Upgrade log since Version 1.00.

RailSim I
Version 1.00		2003/11/16
The first version of the first series RailSim I.
RailSim I
Version 1.42		2006/11/16
The last version of the first series RailSim I.
RailSim II
Version 2.00		2007/03/24
The first version of the second series RailSim II. Whole remake.
RailSim II
Version 2.02		2007/07/09
Supported language switching provisionally (individual distribution).
Implemented plugin-viewer function.
2007/07/19 - 2.02a
Fixed wrong expression of time-scale setting.
Fixed the problem of changing speed when catching up former train.
2007/07/28 - 2.02b
Fixed wrong expression of icon name displayed when pointed.
Fixed the problem that state is not displayed in consist list.
2007/08/01 - 2.02c
Fixed the problem that the train freezes when catching up the waiting train.
RailSim II
Version 2.03		2007/11/16
Implemented simple rail map.
Implemented high-quality screenshot capture.
Added window shadow option.
Displaying the program version in option mode.
2007/11/16 - 2.03a
Changed map control key binding to Slash [ / ].
2007/11/20 - 2.03b
Improved cursor mobility.
Improved key input sensitivity.
2007/12/26 - 2.03c
Fixed a problem around multithreading.
RailSim II
Version 2.10		2008/11/16
Implemented network connection mode.
A car can be deleted from the consist with Delete key in the train edit mode.
RailSim II
Version 2.11		2009/02/07
Added manual control mode and ignore acceleration and deceleration mode.
Implemented splitting and merging of trains.
2009/04/26 - 2.11 additional description
Added new system-defined coordinate systems: "_CAMERA", "_LIGHT" (which enables billboards etc.).
2009/06/06 - 2.11a
Fixed a problem of wrong data source of Diffuse and Ambient material value in *.x files for RS2 train plugins. cf. material-changer
RailSim II
Version 2.12		2009/11/16
Supported downsampling and AVI saving for video (no audio recording yet).
Supported rail blocks and speed limit.
Implemented stereoscopy mode (switch at configulations mode).
Re-ordering in the train list, the car list and the scene list by drag & drop.
Fix: on network connection, UDP port should be opened, not TCP.
RailSim II
Version 2.13		2010/11/23
The function to move a platform along an object is implemented.
The functions to connect platforms dynamically in station plugins (rail-connector, rail-brancher, rail-disconnector) are implemented.
Added turntable test, traverser test and point test by a station plugin as sample plugins.
Supported select-all by Ctrl + A key on text input.
2012/03/20 - 2.13a
Bug fix on building multi track railways, causing the first track disappear.
RailSim II
Version 2.14		2012/08/28
The screen is splittable in neutral mode.
In diagram setting, stop position at station can be specified with number.
Some bug fix on loading layout data.
2012/09/09 - 2.14a
Fixed a bug of train speed display when using screen division.
Fixed a bug that train speed exceeds the plugin setting on speed limit region.
Fixed a crash when using line plugins which contain Profile description.
Fixed a bug that rail of deleted scene is displayed on another scene.
Some bug fix on loading layout data.
RailSim II
Version 2.15		2013/10/26
Model plugins other than train (i.e. station, struct, surface) is now compatible with use of train-free-object (cranks, pistons, etc.).
In edit railway mode, piers and poles can be manually added on railways.
