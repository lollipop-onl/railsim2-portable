RailSim II 操作一覧

画面を見ただけでは分からないショートカットキー等の操作をまとめました。

モード操作動作
全体F1～F6モードグループ切替
1～9サブモード切替
Alt + F4強制終了
F11鑑賞モード、撮影モード切替 (+ Shift で逆順切替)
F12スクリーンショット撮影 (出力先: Picture ディレクトリ)
Ctrl + F12ビデオ撮影開始 (出力先: Video ディレクトリ)
Ctrl + Shift + F12ビデオ撮影終了
Escニュートラルモードへ移行
右ドラッグフォーカス中心にカメラを回転
ホイール回転カメラ前後移動 (PgUp / PgDn で代用可)
Shift + ホイール回転視野角変更 (〃)
Ctrl + 各種操作高速操作
シーン左ドラッグフォーカス水平移動 (建設モード以外)
Shift + 左ドラッグフォーカス垂直移動 (建設モード以外)
Ctrl + S影 ON / OFF
Ctrl + Dステレオ画面 ON / OFF
Ctrl + Z元に戻す (アンドゥ)
Ctrl + Yやり直し (アンドゥのアンドゥ)
Ctrl + ↑ / Ctrl +↓シーン切替
Ctrl + 0 / Numpad 0シミュレーション停止
Ctrl + 1 / Numpad 1等倍速モード
Ctrl + 2 / Numpad 22倍速モード
Ctrl + 3 / Numpad 310倍速モード
Ctrl + 4 / Numpad 4100倍速モード
Ctrl + Mマップ ON / OFF
Ctrl + Nマップ固定切り替え
Slash [ / ] + 左ドラッグマップ表示位置調整
Slash [ / ] + ホイール回転マップ表示倍率調整
プラグイン選択左ドラッグオブジェクトを上下左右に動かす
Shift + 左ドラッグオブジェクトを前後に動かす
右クリックポップアップメニュー表示
線路設置Shift + マウス移動カーソル垂直移動
Alt + マウス移動一時的にスナップ・高度制限 OFF
Space + マウス移動一時的に既存レールとの接続検出 OFF
線路編集↑ / ↓編集モード切替
Alt + 左クリックレール切断 (レール選択モード)
線路編集 /
駅舎編集 /
施設編集		Shift + 選択追加選択
Ctrl + 選択選択解除
Delete選択部分撤去
駅舎設置 /
施設設置		← / →設置角度変更
Ctrl + ← / Ctrl + →設置角度変更 (45°単位)
車輌編成Ctrl + 追加反転した状態で車輌を追加
車輌配置Ctrl + 配置配置後自動的に前進加速
Ctrl + Shift + 配置配置後自動的に後進加速
Tab次の編成を選択 (+ Shift で逆順切替)
← / →速度設定 (+ Ctrl で高速変更)
BackSpace進行方向反転
Delete編成撤去
車輌視点Space運転席モード
車輌視点
(運転席モード)		左ドラッグ視点位置水平移動
Shift + 左ドラッグ視点位置垂直移動
右ドラッグ視線方向移動
Home視点位置リセット
End視線方向リセット
