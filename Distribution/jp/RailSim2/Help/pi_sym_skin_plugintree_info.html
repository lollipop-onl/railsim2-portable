概要

スキンのプラグインツリービューに関する定義です。

生成規則

skin-plugintree-info ::=
PluginTree{
    DefaultBaseColor = color (, color, color, color )opt ;
    DefaultFontColor = color;
    SelectedBaseColor = color (, color, color, color )opt ;
    SelectedFontColor = color;
    FocusFrameColor = color;
}

解説

DefaultBaseColor

ツリー要素の通常の背景色を指定します。

DefaultFontColor

ツリー要素の通常のフォント色を指定します。

SelectedBaseColor

選択要素の背景色を指定します。

SelectedFontColor

選択要素のフォント色を指定します。

FocusFrameColor

選択要素の枠の色を指定します。
