概要

レンズフレアの個々のフレアを定義します。

生成規則

flare-element ::=
( Circle | Hexagon ){
    Distance = float;
    Radius = float;
    InnerColor = color;
    OuterColor = color;
}
flare-element ::=
Texture{
    Distance = float;
    Radius = float;
    TexFileName = filename;
    ( Color = color; )opt
}

解説

Circle

円形のフレアを定義します。

Hexagon

六角形のフレアを定義します。

Distance

光源からフレアまでの距離を指定します。環境プラグインで太陽のレンズフレアを指定する場合、視点から太陽の距離は仮想的に 100 [m] となっています。

Radius

フレアの半径を指定します。

InnerColor

フレアの内側の色を指定します。

OuterColor

フレアの外側の色を指定します。

Texture

テクスチャによる任意形状のフレアを定義します。

TexFileName

フレアに使用するテクスチャファイル名を指定します。

Color

テクスチャに色を付ける場合に指定します。デフォルト値は #ffffffff (無着色) です。
