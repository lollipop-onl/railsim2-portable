概要

レンズフレアのパターンを定義します。

生成規則

lens-flare ::=
LensFlare{
    StartAngle = float;
    ( Twinkle = float; )opt
    ( Inclination = float; )opt
    flare-element*
}

解説

StartAngle

光源方向に対し、フレアの描画を始める視線方向の角度を指定します。

Twinkle

フレアの点滅の度合いを 0.0～1.0 で指定します。デフォルト値は 0.0 です。

Inclination

環境プラグインで使用します。太陽の方向と視線方向のずれに対し、フレアの並びをどの程度ずらすかを指定します。0.0～1.0 程度の値が適切です。環境プラグイン以外では指定する必要はありません。デフォルト値は 0.0 です。
