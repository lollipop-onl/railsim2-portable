概要

スキンの各種カーソルに関する定義です。

生成規則

skin-cursor-info ::=
NormalCursor{ cursor-info }
ResizeCursor1{ cursor-info }
ResizeCursor2{ cursor-info }
ResizeCursor3{ cursor-info }
ResizeCursor4{ cursor-info }

解説

NormalCursor

通常のカーソルを定義します。

ResizeCursor1

上下のリサイズ時のカーソルを定義します。

ResizeCursor2

左下-右上のリサイズ時のカーソルを定義します。

ResizeCursor3

左右のリサイズ時のカーソルを定義します。

ResizeCursor4

左上-右下のリサイズ時のカーソルを定義します。
