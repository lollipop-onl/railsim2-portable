概要

スキンのカーソルに関する情報を定義します。

生成規則

cursor-info ::=
TexFileName = filename;
ImageSize = integer, integer;
( Cursor2DSize = integer, integer; )opt
Cursor2DHotSpot = integer, integer;
( Cursor2DAnimNumber = integer; )opt
( Cursor2DAnimFrame = integer (, integer )* ; )opt

解説

TexFileName

カーソルに使用するテクスチャファイル名を指定します。

ImageSize

画像のサイズをピクセル単位で指定します。

Cursor2DSize

カーソルのサイズを指定します。デフォルト値は ImageSize です。

Cursor2DHotSpot

カーソル内のホットスポット (クリック位置) の座標を指定します。

Cursor2DAnimNumber

アニメーションカーソルのコマ数を指定します。画像には、左上から右方向へ順番にアニメーションのコマが並べられている必要があります。右端へ到達すると下の段へ折り返して並べることができます。デフォルト値は 1 です。

Cursor2DAnimFrame

アニメーションの各コマを表示するフレーム数を指定します。1 フレームは標準で 1/30 秒になります。Cursor2DAnimNumber の数だけ指定することもできますが、省略すると最後の値で残りを補完します。デフォルト値は各 1 です。
