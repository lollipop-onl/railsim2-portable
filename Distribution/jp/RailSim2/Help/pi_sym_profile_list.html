概要

プロファイルプラグインのメイン部分です。

生成規則

profile-list ::=
( profile | wireframe | interval )*

解説

プロファイルプラグインの定義では大きく 3 種類の実装を用いることが出来ます。profile、wireframe、interval です。profile は、レール面やバラストなど、ポリゴンの断面構造を定義します。wireframe は、架線など線のみで表現する場合に用います。interval は、枕木などオブジェクトを一定間隔で配置する場合に用います。これらはひとつのプラグインで複数組み合わせて使うことも出来るので、バラストを profile で作成して枕木を interval で作成するといったことも可能です。
